# Module 7 Assignment — AI Chat Agent

An AI chat agent built with n8n's LangChain nodes (chat trigger + agent).

A learning project from an automation course module.

## Files

- `workflows/module_7_assignment-part1.json` — chat agent workflow (5 nodes)
- `workflows/module_7_assignment-part2.json` — companion agent workflow (3 nodes)

## Setup

1. In n8n, go to Workflows → Import from File and import the JSON files.
2. Replace every `YOUR_...` placeholder with your own webhook and credentials.
3. Connect your own OpenAI account — no credentials are included in this repo.

> Sanitized for public sharing: webhook IDs and credential references were replaced with placeholders. The workflow logic is unchanged.
